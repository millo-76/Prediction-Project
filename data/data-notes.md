# Phase 1 Core Columns

- gameid
- date
- patch
- league (region)
- side (blue/red)
- teamname
- result (1 = win, 0 = loss)

## Ignored for Phase 1

- player-level stats (kills, deaths, assists)
- champion data
- advanced metrics (damage, gold, etc.)

## Notes

- dataset is player-level (10 rows per match)
- must aggregate to match-level
